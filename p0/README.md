## Section 2: Site Inventory (Top Half)

### 1. The Navigation/Menu
* **Line Numbers:** (42-76)
* **Top-Level Classes:** (header, d-flex, align-items-center, sticky-top, container-fluid, container-xl, position-relative, d-flex, align-items-center, justify-content-between, and the navmenu)
* **Research:** d-flex means enabled css flexbox, align-items-center means vertically centered logo and elements, sticky-top means header bar is locked, container-xl is size depending on screen size, navmenu means the template's custom styling selector responsible for menu font styling

### 2. The Logo/Branding
* **Line Numbers:** (45-48)
* **Top-Level Classes:** (logo,d-flex,align-items-center)
* **Research:** Logo is positioned on the far left side of the navigation bar.

### 3. [Hero]
* **Line Numbers:** (81-90)
* **Top-Level Classes:** (Hero,section,dark-background)
* **Research:** dark-background defines the background,Hero defines the height, and d-flex,align-items-center,justify-content-center, and text-center defines the allignment.

### 4. [About section]
* **Line Numbers:** (93-182)
* **Top-Level Classes:** (section,about, section,div,container, row, gy-4, col-md-6, col-lg-5, col-lg-7)
* **Research:** Section applies padding by 60px, container sets maximum width across the screen, row and gy-4 are the responsive vertical spacings, col-md-6 Divides the section into two equal width columns.
## Section 3: Site Inventory (Bottom Half)

### [Resuming section]
* **Line Numbers:** (185-257)
* **Top-Level Classes:** (section,resume,div,container,section-title,row, col-lg-6, resume-item)
* **Research:** section applies padding on top and bottom, resume selects specific custom-css styles, container keeps resume content centered,row and col-lg-6 divides the section into a two column layout

### [services]

### The Footer
